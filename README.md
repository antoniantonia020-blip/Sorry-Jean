# Sorry Den  💜

A heartfelt apology website created with HTML, CSS, and JavaScript.

## Features ✨

- 🎨 Beautiful gradient design with animations
- 💜 Beating heart animation
- 💌 Personalized heartfelt message
- 🎉 Emoji rain celebration on forgiveness
- 📱 Fully responsive mobile-friendly design
- ✨ Smooth animations and transitions
- 🎯 Interactive buttons with multiple responses

## How to Use

Simply open `index.html` in your browser or visit the live site via GitHub Pages.

### Website Features:
1. **View the apology message** - Read the heartfelt apology
2. **Click "I forgive you"** - See a beautiful celebration
3. **Click "Not yet"** - Shows an understanding response
4. **Go back** - Return to the main message

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and animations
- `script.js` - Interactive functionality

## Deployment

This website is deployed using GitHub Pages. Visit the repository settings to view the live link.
